# 📚 AI-Powered Smart Library System

## 🚀 Overview
AI-powered library system using ML + NLP for search, recommendation, and learning support.

## 🧠 Features
- Semantic Search
- Book Recommendation
- AI Book Assistant
- Summarizer
- Study Path Generator
- Demo Mode

## ⚙️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Sentence Transformers
- Pandas

## ▶️ Run Locally
pip install -r requirements.txt
streamlit run app.py

## 🌐 Deployment
Deploy using Streamlit Cloud:
1. Upload to GitHub
2. Select app.py
3. Click Deploy 🚀

## 🏆 Project Goal
AI-powered smart library system for education and research.
